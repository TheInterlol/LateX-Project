# Technical Document Typesetting – Semester Project

This repository contains a semester project for the course **Technical Document Typesetting** (Summer Semester 2025/2026).

## Project Contents

* LaTeX source files
* images and additional assets required for compilation
* bibliography and embedded source code
* LuaLaTeX configuration

## Technologies Used

* LuaLaTeX
* BibLaTeX
* Polyglossia
* Fontsetup (Libertinus)
* Listings
* Geometry

## Compilation

The project is intended to be compiled using:

```bash
lualatex main.tex
biber main
lualatex main.tex
lualatex main.tex
```

## Assignment

The goal of the project was to recreate a technical document according to a provided reference PDF while following specific requirements for typography, bibliography, tables, figures, and source code formatting.
